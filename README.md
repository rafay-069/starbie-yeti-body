## Project Overview
The goal of this enclosure was to house an ESP32 development board, internal wiring, and battery pack securely while maintaining a clean, toy-like aesthetic. 

### Key Design Features:
* **Custom Electronics Fit:** Designed with precise interior tolerances to comfortably accommodate the ESP32 and internal components without cramped wiring.
* **OLED Display Integration:** Features a costom-mapped **22 mm × 11 mm** recessed window cutout on the front shell, built specifically to provide a flush, clean frame for a **0.96-inch OLED display**.
* **MultiColor Print Strategy:** The front face plate is modeled as an entirely separate component rather than a single merged block. This allows for independent slicing and printing in a contrasting filament color, making post-print assembly and dual-tone aesthetics clean and easy.
